# CPU Scheduler Simulator - Round Robin

Un simulatore interattivo dell'algoritmo di scheduling CPU **Round Robin** 

# Descrizione:

Il sito simulerà l'algoritmo Round Robin per lo scheduling dei processi. Ogni processo riceve un time slice per l'esecuzione. Se non completa entro il time slice, viene rimesso in fondo alla coda.

# Come si utilizza:

1. **Aggiungi Time Slice**: Inserisci un valore per il time slice
2. **Aggiungi Processi**: 
   - Process Name: Nome del processo (es. P1)
   - Arrival Time: Quando arriva il processo
   - Burst Time: Quanto tempo ha bisogno
   - Priority: Livello di priorità
3. **Clicca Start**: Esegui la simulazione
4. **Visualizza Risultati**: Viene mostarto diagramma di Gantt e:
  - Average Turnaround Time 
  - Average Response Time 
  - CPU Efficiency 
5. **Reset**: Permette di rifare tutto
