Round Robin Algorithm

The Round Robin algorithm is a preemptive scheduling algorithm, where each process is assigned to the same time to execute part of the job (time slice). If a process does not complete within its time slice, it is moved to the end of the ready queue. It's a starvation free algorithm which means all processes get a fair share of CPU time, without letting any process starve (without being executed)
